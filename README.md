# Sample Data Project

## Overview
This beginner-friendly project demonstrates a simple Python script that creates and displays a small sample dataset. It is part of an introductory Git and GitHub assignment.

## Project Objectives
- Create and manage a local Git repository.
- Track changes with Git commits.
- Publish the project in a public GitHub repository.
- Practice the basic workflow: **add → commit → push**.

## Files
- `sample_data.py` — creates a small sample dataset and prints it.
- `README.md` — project description and instructions.

## Requirements
- Python 3 installed on your computer.

## How to Run
Open a terminal in this folder and run:

```bash
python sample_data.py
```

If your computer uses the `py` command on Windows, run:

```bash
py sample_data.py
```

## Example Output
The script displays sample records for five fictional people, including their ID, age, and department. All records are fictional and are included for learning purposes only.

## Git Workflow Practiced
1. `git add` — select files to track.
2. `git commit` — save a version of the work.
3. `git push` — upload commits to GitHub.
